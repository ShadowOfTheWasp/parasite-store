# Chaz 1.0.0

Original acid-house/rave FM synthesizer: three FM operators with cascade/parallel routing and a sub oscillator; resonant two-stage low-pass filtering and envelope; sixteen steps with rest, accent and per-note glide; 60–180 BPM and swing; playable octave; eight numbered factory/user slots; explicit Start/key consent, Stop and Silence.

Routing: FM voice → original H910-inspired stereo pitch-delay processor → original RE-201-inspired tape/spring unit → master compressor. Inspired DSP, not measured or bit-perfect hardware recreations. All sound is generated; no commercial recordings or song samples.

Standalone Fire APK studio.parasite.chaz version 1.0.0 / code 1, min API 26, all assets embedded, network blocked, no Internet permission. It does not replace the signed Home app. Existing Home 9.1 offline bundles still contain their original three instruments. Adding Chaz there requires a separately signed Home release. Online Hub discovery uses the published catalogue.

Checks cover sequencer/validation and DOM behavior; offline renders for finite output, gating and FM spectral change; JavaScript parsing; Android CI; APK manifest/ZIP/asset parity; published web, Fire catalogue and installer. Physical Kindle tests and listening/latency evaluation remain separate.
