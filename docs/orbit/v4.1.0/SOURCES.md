Mobile processing: first four seconds retained, 50 ms end fade, converted to 44.1 kHz stereo MP3 at 160 kb/s. MIDI root mapping corrects the source filename octave convention (+12 semitones). Playback builds crossfaded sustain loops and uses the nearest recorded root with chromatic resampling. One velocity layer per source note; this is a compact mobile selection, not the entire original library. Users can import their own WAV/AIFF/FLAC/audio recordings per orbit and set root note. No tonal oscillators, shimmer or tape delay are in the sound path. One shared convolution reverb follows the instrument.
