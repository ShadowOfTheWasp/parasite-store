# Parasite Apple v1

Standalone iOS Safari installable PWA proof of concept. Launch via a static HTTPS host rooted at this folder. Apple Home Screen: Safari > Share > Add to Home Screen.

Features: Hub, Orbit oscillator, Melt 8-note synth, Tape texture pads, locally saved Invent synthesizer presets, Web Audio and Service Worker caching.

Limitations: Invent is a preset designer, NOT the connected AI builder. No customer authentication, subscription payments, or server-side module generation. Synths are prototype implementations and are NOT guaranteed equivalent to existing Kindle instruments. Real-device QA and Safari storage/offline tests required before shipping.

This folder is deliberately isolated from the Kindle version.
