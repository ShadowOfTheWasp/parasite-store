# Tron 4.0 sound sources

Mk II Flute recordings by Taijiguy / Leisureland. Source: https://www.leisureland.us/mellotron.htm
Retrieved from the documented mirror https://sound.intercrap.com/strudel/mellotron/strudel.json on 2026-11-22.

The recordist permits use in freeware with attribution, and excludes commercial/for-profit software:
https://www.kvraudio.com/forum/viewtopic.php?start=15&t=236629
https://www.kvraudio.com/forum/viewtopic.php?p=8343564

These samples are included in the free Parasite instrument under those terms. They are not relicensed. No Beatles recordings are included.
Seven source notes (G3, C4, F4, B4, E5, A5, F6; filenames use an octave-lower convention, corrected from measured spectra) are mapped chromatically. Source WAVs were converted to 22.05 kHz mono MP3 at 64 kb/s; source pitch and unlooped tape duration retained.

RE-201-style effects are original Web Audio DSP. Head-mode routing and delay ranges reference Roland's original manual https://cdn.roland.com/assets/media/pdf/RE-201_OM.pdf and the published mode table https://help.uaudio.com/hc/en-us/articles/33538271334164-Roland-RE-201-Space-Echo-Manual . No proprietary DSP or branding artwork copied. This model is not a measured circuit emulation. The 1967 preset suggests the flute timbre; it does not claim documented artist settings.
