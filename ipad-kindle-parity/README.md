# Parasite — Kindle original parity launcher on iPad

Links the real deployed Kindle instrument pages into an iPad-size host. No rewritten or replaced instrument code. Orbit v4.1, Tron v4.0 (Mellotron/Melt family), Slice v1.0.

These are network-hosted **original Kindle web builds**, not a standalone offline port, and the experimental V3 mixer cannot mix their separate Web Audio graphs due cross-origin embedding. Browser microphone and autoplay policies can also differ. If framing is blocked, use OPEN ORIGINAL.

This fixes the immediate misleading mismatch from the simplified V3 prototypes; true integrated parity still requires original source/assets to be copied into the same origin and tested on Safari.
